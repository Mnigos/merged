OSS Leaderboard

Miesięczny ranking prawdziwych kontrybutorów open source. Liczą się tylko PR‑y, które ktoś inny zmergował, ważone popularnością projektu. Bez bazy, bez serwera, bez kosztów.

plan na weekendnazwa robocza5 października 2026

Dlaczego to ma sens

Istniejące rankingi liczą contributions, które każdy nabije skryptem, albo sumują od zawsze, więc szczyt okupują ci sami weterani. Sezon miesięczny i scoring oparty o cudze decyzje merge dają świeży ranking, który trudno oszukać i który ludzie chcą sobie podać dalej.

Decyzje

TanStack Start + React 19

Jedna aplikacja, server functions zamiast API. Nitro preset vercel.

Effect 4 RC

Cały pipeline danych: Stream, Schema, Layer, Schedule. W aplikacji tylko wewnątrz server functions.

Bez bazy i workera

GitHub Actions liczy, Vercel Blob trzyma JSON, Vercel serwuje. Blob przez SDK @vercel/blob.

Bez oRPC, bez turbo

Jeden package, jeden klient. Kontrakt można wyciągnąć później, gdy pojawi się drugi konsument.

Tooling z Rigtch

oxlint z presetami ultracite (core, react, tanstack) i tsgolint, oxfmt, TypeScript 7, Vitest z @effect/vitest.

Tailwind 4

Prosty, ciemny layout, karty OG generowane przez satori w server route.

Scoring

Zasada: liczy się tylko to, co ktoś inny musiał zaakceptować. Wszystkie stałe w jednym pliku, formuła opisana w README.

score(author) = Σ po repo  min( Σ pr_weight × log10(popularity + 10),  CAP_PER_REPO × total )

pr_weight        1.0  zwykły merge przez kogoś innego
                 0.5  self-merge (autor ma write access, czyli maintainer)
                 0    PR do repo pod własnym loginem

popularity       pass 1: liczba różnych autorów zmergowanych w sezonie + WatchEvents w sezonie
                 pass 2: realne gwiazdki z GraphQL dla repozytoriów kandydatów

CAP_PER_REPO     0.3  jedno repo daje maks. 30% wyniku
MIN_POPULARITY   repo z 1 kontrybutorem i 0 gwiazdek waży ~1 punkt, więc farmy nie mają znaczenia

Wykluczenia

  • Loginy kończące się na [bot] oraz lista znanych botów: dependabot, renovate, github-actions, snyk, imgbot, allcontributors.
  • PR‑y do repozytoriów, których właścicielem jest autor.
  • Konta z więcej niż 95% PR‑ów w jednym repo nie trafiają do zakładki globalnej, ale widać ich wynik w wyszukiwarce.
